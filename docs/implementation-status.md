## 남아 있는 항목과 영향

1. **DLC 해독 완료**: 조조의 오산(196.6), 패기웅심(202.8) 본문과 KO/JP 헤더를 검증했다. 두 시나리오가 일반 탐색에 포함된다.
2. **의미 근거 갱신**: 신분·모드 메시지 enum, 무장 원천 구간·열전, 정책 효과 ID와 기본 단위, 전법 종류·효과를 대조했다. 설치와 계정 이용권은 여전히 구분한다. 명승 100·방책 79·시문 20·공로 6등급 도감을 제공한다. 진행 게임의 동적 효과 계산과 역사 이벤트 발동 스크립트 전체는 제공하지 않는다.
3. **화면 검증 제외**: 한국어 게임, 웹 렌더링, Android/iOS 실기기 검사. 이번 사용자 지시로 제외했으며 PASS로 처리하지 않는다.
4. **외부 Preview·정식 공개**: 데이터 게이트가 남아 실제 Vercel 프로젝트 생성·배포·플랫폼 cold start·운영 관찰은 수행하지 않았다. 로컬 패키지 검사가 외부 배포 성공을 뜻하지 않는다.
5. **추가 CE 도감**: 명승·역사/시문 이벤트·공로·방책의 구조별 도감은 계획의 후속 P1 데이터 연구이며 이번 핵심 무장 제품에 포함하지 않았다.

현재 `validate_db.py --release`와 정식 패키지 생성은 실패해야 한다. 검토 패키지는 로컬에서 실행할 수 있지만 Vercel build 및 공개 진입점에서 차단된다. 모든 자동 검사를 통과하더라도 미해결 원천/화면 게이트는 그대로 유지한다.

## r4 이식성과 판정

게임 데이터가 없는 복제본은 합성 Python/API/DOM 검사를 실행한다. 실제 후보 통합 검사는 `CE_TEST_DATABASE` 또는 `run_checks.py --database`로 주입하고 skip을 금지한다. Python 3.12/3.14와 Node 22 CI를 구성했다. 실제 실행 결과는 최신 완료 보고서에서 구분한다. 공개 판정은 공통 evidence gate를 사용하며 플래그만 바꾸어 우회할 수 없다.
